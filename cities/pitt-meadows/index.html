Pitt Meadows questions

The ones we get from this city.

I'm in South Bonson and my neighbour's door spring broke last month. Bad sign?

For townhouse complex builds, yes — same install date, same spec, same age, same failure schedule. Worth booking proactively if you don't want a 7 a.m. surprise.

Townhouse complex — should the strata pay?

Depends on your bylaws. Most BC townhouse strata cover the door but not the spring (consumable). Check your bylaws. We can quote the strata directly for batch service across units.

Heavy fog every morning — does it really hurt my hardware?

Yes, slowly. Cables fray faster, bottom brackets rust earlier. Springs are mostly OK. The two-spring tier includes cables free, which is the right answer here.
